# Daftar-Produk-Toko
## CARA MENJALANKAN

1. Buka project Daftar Produk Toko di Apache NetBeans IDE 25.
2. Pastikan JavaFX dan semua dependensi Maven sudah terpasang dengan benar.
3. Klik kanan pada project, lalu pilih **Clean and Build**.
4. Jika proses build berhasil, jalankan aplikasi menggunakan Maven dengan perintah `javafx:run`.
5. Tunggu sampai aplikasi Daftar Produk Toko terbuka.
6. Masukkan nama produk, pilih kategori (Makanan atau Minuman), lalu isi harga produk.
7. Klik tombol **Tambah** agar produk masuk ke dalam tabel.
8. Untuk mencari produk, masukkan nama produk pada kolom pencarian lalu klik **Cari**.
9. Pilih produk pada tabel untuk melihat informasi lengkapnya melalui tombol **Lihat Detail**.

## FITUR APLIKASI

- Menambahkan produk dengan kode yang dibuat secara otomatis, seperti PRD001, PRD002, dan seterusnya.
- Memilih kategori produk, yaitu Makanan atau Minuman.
- Memeriksa input agar nama produk tidak kosong dan harga harus lebih dari nol.
- Menampilkan data produk dalam tabel yang berisi kode, nama, kategori, dan harga.
- Mencari produk berdasarkan nama menggunakan tombol Cari.
- Melihat informasi lengkap produk yang dipilih melalui tombol Lihat Detail.
- Data produk hanya disimpan sementara selama aplikasi berjalan dan tidak menggunakan database.
